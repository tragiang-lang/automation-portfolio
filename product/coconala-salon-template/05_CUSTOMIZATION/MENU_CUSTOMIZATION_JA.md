# メニュー（サービス）カスタマイズガイド

## 単一の情報源: SERVICESシート

予約フォーム（`/reservation`）のメニュー選択・料金・所要時間も、
トップページの「メニュー」セクションの表示も、**どちらも同じ
`SERVICES`シートを情報源としています**（`getServices`）。以前のバージョン
では両者が別々のファイルで管理されていましたが、現在は`SERVICES`シート
を編集するだけで両方に反映されます。

## SERVICESシート

対象: `03_GOOGLE_SHEETS/SHEET_SETUP_GUIDE_JA.md`で作成したスプレッド
シートの`SERVICES`タブ。

| 列 | 内容 | 必須/任意 |
|---|---|---|
| `ServiceID` | メニューの一意なID（例: `SV001`） | 必須 |
| `Name` | メニュー名 | 必須 |
| `DurationMinutes` | 所要時間（分） | 必須 |
| `Price` | 価格（円、数値のみ） | 必須 |
| `Active` | `true`で表示、`false`で非表示 | 必須 |
| `StaffRequired` | `true`の場合、このメニューは担当スタッフの指名が必要 | 必須 |
| `DisplayOrder` | 表示順（小さい順） | 必須 |
| `Description` | トップページのメニュー説明文 | 任意 |
| `Category` | トップページでのカテゴリ分け（例: 「ジェルネイル」） | 任意 |

**予約の受付・料金計算・所要時間の判定は、必ずこのシートの値が
使われます。** `Description`/`Category`は表示専用の項目で、予約ロジック
には一切影響しません。

### `Description`/`Category`（任意項目）について

この2列は空欄のまま運用しても問題ありません（エラーにはなりません）。
入力すると、トップページの「メニュー」セクションに説明文とカテゴリが
表示されるようになります。`Category`を複数のメニューで共通の文言に
すると、メニューが7件以上あり、かつカテゴリの種類が2つ以上ある場合に
自動でカテゴリごとにグループ分けして表示されます（6件以下、または
カテゴリの種類が1つだけの場合はグループ分け表示にはなりません）。

既存のスプレッドシートをお使いの場合、この2列を追加しなくても今までと
同様に動作します（メニュー名・所要時間・価格のみのシンプルな表示に
なります）。

### メニューを追加する

新しい行に、他と重複しない`ServiceID`（例: 既存が`SV001`〜`SV003`なら
`SV004`）、メニュー名、所要時間、価格、`Active`=`true`、
`StaffRequired`、表示順を入力します。`Description`/`Category`は
お好みで追加してください。

### メニューを削除する（非表示にする）

行を削除するのではなく、**`Active`列を`false`に変更する**ことを
推奨します。過去の予約データ（`RESERVATIONS`シート）が`ServiceID`を
参照して残っているため、行そのものを削除すると整合性が崩れる可能性が
あります。

### 名前・価格・所要時間・説明文・カテゴリを変更する

該当する列のセルを直接編集するだけです。

### 表示順を変更する

`DisplayOrder`列の数値を変更します。小さい順に表示されます。

### 触ってはいけないもの

`ServiceID`は一度使い始めたら変更しないでください。既存の予約データ
（`RESERVATIONS`シートの`ServiceID`列）がこの値を参照しています。

### 反映のタイミング

シートを保存すると、次回のページ表示（`getServices`呼び出し）から
即座に反映されます。再デプロイは不要です。
