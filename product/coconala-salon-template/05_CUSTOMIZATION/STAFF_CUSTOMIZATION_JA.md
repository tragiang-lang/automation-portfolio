# スタッフ カスタマイズガイド

本ガイドはスタッフの**内容**（名前・役職・紹介文など）の変更方法です。
スタッフ紹介の**見た目のレイアウト**（グリッド表示/横並びプロフィール
表示など）を変更したい場合は
[`DESIGN_CUSTOMIZATION_JA.md`](DESIGN_CUSTOMIZATION_JA.md#4-個別レイアウト設定)（「4.4
スタッフレイアウト」）
を参照してください。

## 単一の情報源: STAFFシート

予約フォーム（`/reservation`）のスタッフ選択・カレンダー連携も、
トップページの「スタッフ紹介」セクションの表示も、**どちらも同じ
`STAFF`シートを情報源としています**（`getStaff`）。以前のバージョンでは
両者が別々のファイルで管理されていましたが、現在は`STAFF`シートを
編集するだけで両方に反映されます。

## STAFFシート

対象: スプレッドシートの`STAFF`タブ。

| 列 | 内容 | 必須/任意 |
|---|---|---|
| `StaffID` | スタッフの一意なID（例: `ST001`） | 必須 |
| `Name` | スタッフ名（予約フォーム・トップページ両方に表示される名前） | 必須 |
| `Active` | `true`で表示、`false`で非表示 | 必須 |
| `CalendarID` | このスタッフ専用のGoogleカレンダーID（空欄可） | 必須列（値は空欄可） |
| `DisplayOrder` | 表示順（小さい順） | 必須 |
| `Role` | トップページに表示する役職（例: 「店長」） | 任意 |
| `Bio` | トップページに表示する紹介文 | 任意 |
| `ImagePath` | トップページに表示する写真のパス | 任意 |

### `Role`/`Bio`/`ImagePath`（任意項目）について

この3列は空欄のまま運用しても問題ありません（エラーにはなりません）。
入力すると、トップページの「スタッフ紹介」セクションに役職・紹介文・
写真が表示されるようになります。空欄のスタッフは、これまでどおり
名前の頭文字を表示するアイコンで代用されます。

**`ImagePath`は外部サイトの画像URLではなく、ご自身のNext.jsプロジェクト
の`public/images/staff/`配下に置いた画像ファイルへのパスを指定して
ください**（例: `/images/staff/staff-05.jpg`）。差し替え手順は
[`IMAGE_CUSTOMIZATION_JA.md`](IMAGE_CUSTOMIZATION_JA.md)を参照してください。
外部サイトのURL（`https://...`）を指定するとエラーになります（本
テンプレートは外部ドメインの画像最適化を許可していません — セキュリティ
と表示の安定性のための意図的な制限です）。必ず`/images/staff/...`の形の
パスを指定してください。

既存のスプレッドシートをお使いの場合、この3列を追加しなくても今までと
同様に動作します（名前のみのシンプルな表示になります）。

### スタッフを追加する

新しい行に、他と重複しない`StaffID`、名前、`Active`=`true`、
必要であれば`CalendarID`、表示順を入力します。`Role`/`Bio`/`ImagePath`
はお好みで追加してください。

### スタッフを削除する（非表示にする）

行を削除するのではなく、**`Active`列を`false`に変更する**ことを
推奨します。過去の予約データが`StaffID`を参照しているためです。

### 表示名・役職・紹介文を変更する

該当する列を直接編集します。

### 有効/無効を切り替える

`Active`列を`true`/`false`で切り替えます。

### スタッフ・カレンダーの対応付け

`CalendarID`列にスタッフ専用のGoogleカレンダーIDを設定すると、その
スタッフの予約はそのカレンダーに登録されます。空欄の場合は、
`CONFIG`シートの`calendar.id`がフォールバックとして使われます。
カレンダーIDの調べ方は
[`../04_SETUP_GUIDE/CALENDAR_SETUP_JA.md`](../04_SETUP_GUIDE/CALENDAR_SETUP_JA.md)
を参照してください。

### 「指名なし（お任せ）」の挙動

`CONFIG`シートの`staff.anyAvailableOption`が`true`の場合、予約フォーム
に「指名なし（お任せ）」という選択肢が表示され、その時間帯に対応可能な
スタッフが自動的に案内されます。`features.staffSelection`（スタッフ
指名機能そのもの）を`false`にする場合は、`staff.anyAvailableOption`
も`false`にしておくことを推奨します（スタッフ指名自体を行わない設計と
整合させるためです）。

### 触ってはいけないもの

`StaffID`は一度使い始めたら変更しないでください。既存の予約データが
この値を参照しています。また、シートには社内向けの識別子以上の情報
（住所・連絡先など）を入力しないでください。

### 反映のタイミング

シートを保存すると、次回のページ表示（`getStaff`呼び出し）から即座に
反映されます。再デプロイは不要です。

## スタッフ写真について

同梱のスタッフ画像は実在の人物ではなく、本テンプレート用に作成された
イラストです。実在しない人物の名前・プロフィールを、実在の人物の
写真と結びつけて公開しないようご注意ください。
