# NATURAL（ナチュラル）

**ナチュラル・やさしく親しみやすいデザイン**

温かみのある砂色の背景に、深いアースブラウンの文字、彩度を抑えた
セージグリーンのアクセントを組み合わせた、オーガニックで癒し系の
配色です。Femmeと同じ左右2カラムのHero・masonryギャラリーを使いつつ、
メニューは装飾のないミニマルな価格表にすることで、より肩の力が抜けた
親しみやすい印象にしています。

## 構成（`config/design-presets.ts` より）

| 項目 | 値 |
|---|---|
| 配色テーマ (`theme`) | `natural` — 背景 `#f6f2e9` / アクセント `#56684a`（セージグリーン） |
| 見出しフォント | Shippori Mincho（和文） / Cormorant Garamond（欧文） — Kinariと共通の上品なセリフ体 |
| Hero レイアウト | `split` — テキストと写真を左右2カラムに分ける構成 |
| メニュー レイアウト | `minimal-price-list` — 罫線もカードも使わない、ミニマルな価格表 |
| スタッフ レイアウト | `portrait-grid` — 縦長ポートレート写真のグリッド |
| ギャラリー レイアウト | `masonry` — タイルの大きさを変化させる雑誌風レイアウト |
| セクション順序 | 既定順（hero → concept → menu → staff → gallery → reservation → salon-features → customer-flow → faq → access → contact） |
| セクション表示 | 任意セクションはすべて表示 |

## こんなイメージに向いています

自然体で親しみやすい雰囲気を大切にしたいサロン。オーガニック・
癒し系の打ち出し方をしたい場合に向いた構成です（これは方向性の説明
であり、特定業種専用という意味ではありません）。
