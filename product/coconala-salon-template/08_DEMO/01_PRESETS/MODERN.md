# MODERN（モダン）

**シンプル・都会的で洗練されたデザイン**

Kinariよりも冷たさのあるクリスプなニュートラル背景に、より濃い黒に
近い文字、深いティール（青緑）のアクセントを組み合わせた、
6プリセットの中でもっとも現代的・都会的な配色です。和文・欧文とも
サンセリフのみで統一した、セリフ体を一切使わない唯一の組み合わせです。

## 構成（`config/design-presets.ts` より）

| 項目 | 値 |
|---|---|
| 配色テーマ (`theme`) | `modern` — 背景 `#f7f7f5` / アクセント `#3d6b63`（ディープティール） |
| 見出しフォント | Zen Kaku Gothic New（和文） / Inter（欧文） — セリフ体を使わない唯一の組み合わせ |
| Hero レイアウト | `split` — テキストと写真を左右2カラムに分ける構成 |
| メニュー レイアウト | `card-grid` — メニュー1件ごとに枠線付きカードでグリッド表示 |
| スタッフ レイアウト | `horizontal-profile` — 正方形写真＋プロフィールを横並びにした1人1行形式 |
| ギャラリー レイアウト | `grid` — 元のアスペクト比を保った定番グリッド |
| セクション順序 | Gallery を Staff より前に配置（hero → concept → menu → **gallery** → staff → …） |
| セクション表示 | 任意セクションはすべて表示 |

## こんなイメージに向いています

シンプルで都会的な印象を打ち出したいサロン。装飾を抑え、機能的で
すっきりした見た目にしたい場合に向いた構成です（これは方向性の説明
であり、特定業種専用という意味ではありません）。
