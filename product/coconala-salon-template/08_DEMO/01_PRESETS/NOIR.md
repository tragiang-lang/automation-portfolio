# NOIR（ノワール）

**高級感・モダンで洗練されたデザイン**

温かみのある濃いチャコール（純粋な黒ではありません）を背景に、
シャンパンゴールドの見出し・銅色のアクセントを組み合わせた、
高級感のあるダークテーマです。フルスクリーンの写真Hero、装飾を
抑えた価格表、1枚の写真を大きく見せるギャラリーなど、少ない要素を
大きく・自信を持って見せるレイアウトで統一しています。

## 構成（`config/design-presets.ts` より）

| 項目 | 値 |
|---|---|
| 配色テーマ (`theme`) | `noir` — 背景 `#1c1917`（濃いチャコール） / アクセント `#c17b5e` |
| 見出しフォント | Shippori Mincho（和文） / Playfair Display（欧文） |
| Hero レイアウト | `fullscreen` — 写真を画面いっぱいに敷いた定番構成（ダーク配色で高級感を演出） |
| メニュー レイアウト | `minimal-price-list` — 罫線もカードも使わない、ミニマルな価格表 |
| スタッフ レイアウト | `horizontal-profile` — 正方形写真＋プロフィールを横並びにした1人1行形式 |
| ギャラリー レイアウト | `feature-editorial` — 1枚を大きく見せる「主役写真」＋周囲の小さな写真 |
| セクション順序 | Gallery を Menu より前に配置（hero → concept → **gallery** → menu → staff → …） |
| セクション表示 | 任意セクションはすべて表示 |

## こんなイメージに向いています

高級感・モードな雰囲気を打ち出したいサロン。写真点数を絞り、1枚1枚を
大きく見せたい場合に向いた構成です（これは方向性の説明であり、特定
業種専用という意味ではありません）。
