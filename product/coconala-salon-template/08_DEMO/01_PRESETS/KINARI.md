# KINARI（凛）

**自然・温かみのあるナチュラルなデザイン**

初期設定（デフォルト）のデザインプリセットです。和紙のような
オフホワイトの背景に、落ち着いた墨色の文字、控えめな臙脂色の
アクセントを組み合わせた、静かで上質な「和」の雰囲気です。

## 構成（`config/design-presets.ts` より）

| 項目 | 値 |
|---|---|
| 配色テーマ (`theme`) | `kinari` — 背景 `#faf7f2` / アクセント `#9c4b3f` |
| 見出しフォント | Shippori Mincho（和文） / Cormorant Garamond（欧文） |
| Hero レイアウト | `fullscreen` — 写真を画面いっぱいに敷き、左下に見出し・CTAを重ねる構成 |
| メニュー レイアウト | `editorial-list` — カテゴリ見出し＋罫線区切りのリスト |
| スタッフ レイアウト | `portrait-grid` — 縦長ポートレート写真のグリッド |
| ギャラリー レイアウト | `grid` — 元のアスペクト比を保った定番グリッド |
| セクション順序 | 既定順（hero → concept → menu → staff → gallery → reservation → salon-features → customer-flow → faq → access → contact） |
| セクション表示 | 任意セクションはすべて表示 |

## こんなイメージに向いています

流行に左右されない、落ち着いた雰囲気を大切にしたいサロン。ネイル・
まつげサロンに限らず、和のテイストや「静けさ」「丁寧さ」を打ち出したい
店舗の第一候補になるデザインです（これは方向性の説明であり、特定業種
専用という意味ではありません）。
