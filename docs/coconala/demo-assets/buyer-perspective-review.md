# 買い手視点レビュー（日本人ココナラ購入者を想定）

## Salon

**最初の画像で3秒で分かるか？**
Yes — `salon-01-hero.jpg` は実際のサロンサイトのHero（キャッチコピー
「静けさの中で、指先とまなざしを整える。」＋予約導線）で、ネイル
サロン向けサイトだと即座に分かる。

**2枚目でワークフローが分かるか？**
Yes（条件付き） — メニュー画面（`salon-02-service.jpg`）で実際の価格が
見えることは強い訴求になる。ただし「予約導線」までは今回の実撮影素材
だけでは見せきれていない（予約ウィザードがGAS未接続でブロックされた
ため）。6プリセットショーケース画像と組み合わせることで「導入後に
自分好みのデザインに変えられる」という差別化は明確に伝わる。

**スクリーンショットで本物の製品だと分かるか？**
Yes — 実際にビルド・起動した画面をそのまま撮影しており、加工した
モックアップではない。メニュー・価格・スタッフ紹介文など、テンプレート
としてすぐ使える具体性がある。

**動画で技術知識がなくても価値が分かるか？**
Yes（ストーリーボード上は） — ただし予約完了までを見せられない現状の
制約は、動画の説得力をやや弱める。将来的にGAS接続済みの環境で予約
ウィザード〜完了までを追加撮影することを推奨する。

**存在の証拠として十分か？**
Yes — 実UIスクリーンショット＋既存の6プリセット実撮影素材の組み合わせ
は、十分な「実在する製品」の証拠になる。

**含まれる範囲が分かるか？**
Partially — 既存の `coconala-service-listings.md` に詳細な「できる
こと/できないこと」が整理済みで、そちらと組み合わせて提示すれば
明確。単体の画像だけでは「予約フォームは自分で導入設定が必要」という
前提までは伝わらない → リスティング本文でのフォロー必須。

**汎用のWeb制作との違いが分かるか？**
Yes — 「Googleカレンダー連携・二重予約防止・6デザインプリセット」は
テンプレート特有の差別化として画像・図解で伝えやすい。

## Site Report

**最初の画像で3秒で分かるか？**
**現状 No** — 買い手向けに使える実UIスクリーンショットが1枚も無い
（LIFFゲートのため）。Hero画像は装飾＋コピーのみで訴求する必要があり、
「実際の画面」を見せられない分、説得力は通常より弱い。

**2枚目でワークフローが分かるか？**
図解（ワークフローグラフィック）でのみ Yes。実UIでは現状 No。

**スクリーンショットで本物の製品だと分かるか？**
**現状 No** — 内部エビデンス（LIFF未設定エラー画面）はあるが、これは
買い手向けには使えない。買い手が実UIを見るには、実LIFF環境での撮影
（`manual-device-capture.md`）を先に完了させる必要がある。

**動画で価値が分かるか？**
**現状 No** — ストーリーボードは用意したが、素材が撮影不能
（NOT READY）。

**存在の証拠として十分か？**
**現状不十分。** GASのソースコード（`Api.ts`のSUBMIT_REPORT実装、
Sheets/Drive書き込みロジック）は実在し検証済みだが、これは「買い手が
見て分かる証拠」ではなくコードレベルの証拠に留まる。買い手向けには、
最低限「実LIFF環境での現場選択〜報告フォーム〜写真添付」のUI
スクリーンショットが必要。

**含まれる範囲が分かるか？**
既存の `coconala-service-listings.md` に非常に詳細な整理があり
（LIFF本人確認の限界、集計機能が無いこと等も正直に記載済み）、
文章としては十分。画像面が追いついていない。

**汎用開発との違いが分かるか？**
図解・文章レベルでは Yes（LIFFログイン〜Sheets/Drive記録までの
一気通貫の技術基盤が既に動作確認済みであること）。ただし実UIの
裏付けが無いと、買い手には「本当に動くのか」という懸念が残る。

## 総合結論

- **Salon**: 現状の実撮影素材＋既存の6プリセット素材で、ココナラ出品の
  最低限の視覚的証拠は揃っている（READY FOR COCONALA ASSET
  PREPARATION）。予約ウィザードの実接続後の追撮影で更に強化できる。
- **Site Report**: 文章・コード面の裏付けは強いが、**買い手が見て
  分かる実UI画像がゼロ**という致命的なギャップがある。実LIFF・実
  バックエンド環境での撮影（`manual-device-capture.md`）を完了する
  までは、視覚素材としては **NOT READY** と判断する。
