# Salon 録画スクリプト（LOCAL RECORDING）

## Environment

- Device/Viewport: Desktop 1440×900相当、Mobile 390–412×844–915相当
- Browser: 最新版 Chrome
- URL: `http://localhost:4001`（ローカル `npm run dev`）
- 必要な環境変数: なし（LP・メニュー・お問い合わせフォームの表示のみなら不要）
- デプロイ必要: いいえ（ローカルで完結）
- LINE必要: いいえ
- Google連携必要: いいえ（予約ウィザードを見せる場合は必要になるが、
  本スクリプトでは予約ウィザードを録画対象から除外している — 上記
  storyboardの注意事項参照）

## Preparation

1. リポジトリの `apps/salon-portfolio/web` で `npm run dev -- -p 4001` を起動し、
   `http://localhost:4001` が正常に表示されることを確認する。
2. ブラウザのタブ・拡張機能のバッジ・ブックマークバーなど、収録に不要な
   UIを非表示にする。
3. デベロッパーツール（DevTools）は閉じておく（デバッグUIを映さない）。
4. コンソールにエラーが出ていないか確認する（意図しないエラーが映り込む
   ことを防ぐ）。
5. お問い合わせフォームは事前入力せず、まっさらな状態から始める。

## Recording steps

1. `http://localhost:4001` を開く。
2. 2秒静止（Heroのキャッチコピーを見せる）。
3. ゆっくり下にスクロールし、Concept→Menuセクションを見せる（合計6秒程度）。
4. Menuセクションでスクロールを止め、価格が読める速度で2〜3秒静止。
5. ページ上部の「お問い合わせ」リンク、または `#contact` へスクロールで移動。
6. お名前欄に「田中 花子」と入力。
7. メールアドレス欄に「hanako.tanaka@example.com」と入力。
8. 電話番号欄に「090-1234-5678」と入力。
9. お問い合わせ内容欄に「ネイルサロンの予約について問い合わせです。
   地元のサロン向けに使いたいと思っています。」と入力。
10. プライバシーポリシー同意のチェックボックスをオンにする。
11. 2秒静止（入力済みフォーム全体を見せる）。
12. **送信ボタンはクリックしない**（実際には送信されないため）。
13. 別カットとしてモバイル幅（390×844程度）でHeroを開き直し、3秒静止。

## After recording

- 個人情報が映っていないか確認（実在の氏名・メール・電話番号を使って
  いないか — 上記のデモデータのみ使用）。
- 開発者ツール・コンソールログ・エラーバナーが映っていないか確認。
- 「送信」後の画面が映っていないか確認（実送信されないため、映すと
  誤解を招く）。
- 日本語テキストが正しく読めるか確認。
