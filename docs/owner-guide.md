# ご予約・お問い合わせの確認方法（オーナー様向けガイド）

このページは、そのままGoogleドキュメントに貼り付けてお使いいただけます。

## 1. ご予約を確認する

1. Googleスプレッドシート（このサイト専用のシート）を開きます。
2. 下部のタブから **「RESERVATIONS」** シートを開きます。
3. 新しい行が、お客様からのご予約希望です。`Name`（お名前）・`Email`・
   `Phone`・`ServiceID`（ご希望のメニュー）・`Date`（日付）・`Time`
   （時間）・`Notes`（備考）をご確認ください。
4. `Status`列が `処理中` のままの行がないか、時々ご確認ください（通常は
   自動的に `受付済` または `要確認` に変わります）。

## 2. お問い合わせを確認する

1. 同じスプレッドシートの **「INQUIRIES」** タブを開きます。
2. 新しい行が、お客様からのお問い合わせです。`Name`・`Email`・
   `Phone`（任意）・`Message`（お問い合わせ内容）・`CreatedAt`（受付日時）
   をご確認ください。

## 3. メール通知の仕組み

```
お客様がフォームを送信する
        ↓
内容がGoogleスプレッドシートに保存される
        ↓
お客様に確認メールが自動送信される
        ↓
オーナー様に通知メールが自動送信される
```

ご予約・お問い合わせのどちらも、この流れは同じです。フォームは
Googleフォームではなく、サイト内の予約・お問い合わせ画面から直接
送信される仕組みですが、「送信されたら記録されて、両方にメールが届く」
という結果は同じです。

## 4. 重要：ご予約は「希望」であり、確定ではありません

お客様からご予約フォームが送信されても、それは**ご予約希望を
受け付けた**段階です。**自動的に予約が確定したわけではありません。**
確認メールにも「ご予約が確定しました」ではなく「ご予約希望を
受け付けました」と記載されます。日時の変更やお断りが必要な場合は、
オーナー様から直接お客様にご連絡ください。

（システムは可能な限り自動で空き状況を確認し、Googleカレンダーに
予定を登録しますが、登録に失敗した場合は `Status`列が `要確認` に
なり、その旨の通知メールがオーナー様に届きます。この場合は必ず
手動でご確認・ご連絡ください。）

## 5. 基本的なトラブルシューティング

うまく動作しないときは、以下を順番にご確認ください。

- **お問い合わせ・ご予約が届かない**
  → スプレッドシートの `RESERVATIONS`／`INQUIRIES`タブに行が
    追加されているか確認してください。行自体が追加されていない
    場合は、サイトの管理者（開発者）にご連絡ください。
- **スプレッドシートには記録されているのにメールが来ない**
  → `EMAIL_LOG`タブを開き、該当する記録の`Status`列が`sent`か
    `failed`かを確認してください。`failed`の場合は`ErrorMessage`列に
    理由が記録されています。
- **オーナー様へのメールだけ届かない**
  → `CONFIG`シートの`email.ownerNotifyAddress`の行に、正しい
    メールアドレスが入っているかご確認ください。
- **お客様へのメールだけ届かない**
  → お客様が入力したメールアドレスに誤りがなかったか、
    `RESERVATIONS`／`INQUIRIES`タブの該当行でご確認ください。
- **エラーの詳細を知りたい**
  → `ERROR_LOG`タブに、開発者向けの詳細なエラー記録があります
    （お客様の個人情報は記録されません）。サイトの管理者に
    このタブの内容を共有してください。

上記でも解決しない場合は、サイトの管理者（開発者）にご連絡ください。

## 参考：他の業種に切り替える場合（開発者向け）

同じ仕組みのまま、`CONFIG`シートの値を変更するだけで、Nails Salon /
Hair Salon / Workshop / Class organizer のいずれにも対応できます
（コンポーネントのコードやメール送信の仕組みは変更不要です）。

| 変更する項目 | 例 |
|---|---|
| `business.name` / `business.tagline` など | 屋号・キャッチコピー |
| `SERVICES`シートの各行 | メニュー／ワークショップ／クラスの一覧 |
| `labels.service` | 「メニュー」→「ワークショップ」「クラス」など |
| `labels.bookingCta` | 「ご予約はこちら」→「参加申込み」など |
| `labels.inquiryMessage` | 「お問い合わせ内容」→「お問い合わせ・ご質問」など |
| `content.*`（Hero/Concept/CTA文言） | 業種に合わせた説明文 |
| `email.ownerNotifyAddress` | 通知メールの宛先 |
| デザインプリセット（`SALON_DESIGN_PRESET`環境変数） | `starter` を指定すると、Hero・メニュー・お問い合わせ・予約案内のみのシンプルな1ページ構成になります |

詳細なキー一覧は `docs/config-and-sheets-guide.md` を参照してください。
