# LINE の設定 — Demo Hair Salon（デモ）

## 仕組み

```text
LINE ──► 署名確認プロキシ（Cloudflare Worker）──► Google Apps Script ──► スプレッドシート
          │ 本物の LINE からの通信か「署名」で確認
          └ 確認できない通信はここで止め、Apps Script には送りません
```

Google Apps Script は LINE の「署名」を確認できないため、確認を署名確認プロキシが行います。
Apps Script はプロキシからの通信だけを受け付けます（`WEBHOOK_KEY`）。

## 1. LINE Developers で確認する値

| 値 | 場所 | 設定先 |
|---|---|---|
| チャネルシークレット | 「チャネル基本設定」 | 署名確認プロキシ（`LINE_CHANNEL_SECRET`） |
| チャネルアクセストークン（長期） | 「Messaging API設定」 | Apps Script（`LINE_CHANNEL_ACCESS_TOKEN`）、リッチメニュー登録時の作業者の環境変数 |

どちらもパスワードと同じ扱いです。ファイル・チャット・スプレッドシートに書かないでください。

## 2. 署名確認プロキシを置く（作業者向け）

```bash
cd line/webhook
npm install
npm test                                  # 署名確認のテスト
cp wrangler.toml.example wrangler.toml
npx wrangler login
npx wrangler secret put LINE_CHANNEL_SECRET   # 1 のチャネルシークレット
npx wrangler secret put GAS_WEBAPP_URL        # GAS の …/exec の URL
npx wrangler secret put GAS_WEBHOOK_KEY       # Apps Script の WEBHOOK_KEY と同じ値
npx wrangler deploy                           # https://….workers.dev の URL が表示されます
```

## 3. Webhook を設定する

1. LINE Developers →「Messaging API設定」→「Webhook URL」に、手順2で表示された **workers.dev の URL** を設定します（Apps Script の URL ではありません）。
2. 「検証」を押して「成功」と表示されることを確認します。
3. 「Webhookの利用」をオンにします。
4. LINE Official Account Manager の「応答設定」で Webhook をオンにします（自動応答メッセージは必要に応じてオフ）。
5. 任意: 「Webhookの再送」をオンにすると、一時的な障害のときに LINE が通信を再送します。同じ通信が2回届いても、受付は1回だけ記録されます。

## 4. リッチメニューを登録する（作業者向け）

リッチメニュー「demo-hair-salon-salon-basic-v1」（2500×1686px、ボタン6個）を、ファクトリーから登録します。
トークンは環境変数でだけ渡します（ファイルに保存しません）。

```bash
# 1) 確認だけ（LINE には何も送りません）
npm run factory -- line-deploy --project projects/2026/demo-hair-salon --env test
# 2) テスト用 LINE 公式アカウントに登録
LINE_CHANNEL_ACCESS_TOKEN=（テスト用のトークン） npm run factory -- line-deploy --project projects/2026/demo-hair-salon --env test --live
# 3) E2E_TEST.md で確認したあと、本番アカウントに登録
LINE_CHANNEL_ACCESS_TOKEN=（本番のトークン） npm run factory -- line-deploy --project projects/2026/demo-hair-salon --env production --live
```

- 登録は「作成 → 画像の登録 → 確認 → 全員に表示」の順で行い、**古いメニューは削除しません。** 前のメニューは記録され、いつでも戻せます（[ROLLBACK.md](ROLLBACK.md)）。
- 登録結果（LINE が発行するメニューID）は `line/deployment-history.json` に記録されます。
- リッチメニューは **スマートフォンの LINE アプリでだけ** 表示されます（パソコン版 LINE には表示されません）。表示の反映には少し時間がかかることがあります。
