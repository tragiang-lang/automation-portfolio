# セットアップ手順 — Demo Nail Salon（デモ）

この手順書は、LINE リッチメニューと Google スプレッドシートを使った自動受付の初期設定を、順番どおりにまとめたものです。
各手順の詳しい説明は、リンク先の資料にあります。「作業者向け」とある手順は、納品担当の作業者が行います。
作業時間の目安: 90〜120分。

## 仕組み（全体像）

```text
お客様のスマートフォン（LINE アプリ）
   │ リッチメニューのボタンをタップ
   ▼
LINE ──► 署名確認プロキシ（本物の LINE からの通信かを確認）──► Google Apps Script ──► スプレッドシート
                                                                   │
                                                                   └─► LINE で自動返信・オーナー様へ通知メール
```

## 0. 事前に用意するもの

- LINE 公式アカウント（Messaging API を有効化済み）
- Google アカウント（スプレッドシートと Apps Script を作成するアカウント）
- Cloudflare アカウント（無料プランで可。署名確認プロキシを置く場所です）
- スマートフォン（LINE アプリ）。**リッチメニューはパソコン版 LINE には表示されません。**
- リッチメニュー画像は納品物に含まれています（`rich-menu/rich-menu.png`、2500×1686px、145KB）。

## 1. スプレッドシートを作る

1. Google ドライブで新しいスプレッドシートを作成します（名前は自由です。例: 「Demo Nail Salon 受付管理」）。
2. URL の `/d/` と `/edit` の間の文字列が **スプレッドシートID** です。控えておきます。

シートと列の一覧は [SPREADSHEET_SETUP.md](SPREADSHEET_SETUP.md) を参照してください。

## 2. Apps Script にプログラムを入れる（作業者向け）

```bash
cd gas
npm install
npm test          # 全テストが通ることを確認
npm run build
cp .clasp.json.example .clasp.json   # scriptId を記入
npx clasp push
```

詳しくは [GAS_SETUP.md](GAS_SETUP.md) を参照してください。

## 3. スクリプト プロパティを設定する

Apps Script エディタ →「プロジェクトの設定」→「スクリプト プロパティ」に次を登録します。
**これらの値はスプレッドシートやチャット、Git には絶対に書かないでください。**

| プロパティ | 内容 |
|---|---|
| `SPREADSHEET_ID` | 手順1のスプレッドシートID |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Developers →「Messaging API設定」のチャネルアクセストークン（長期） |
| `WEBHOOK_KEY` | 32文字以上のランダムな英数字（パスワード生成ツールで作成）。署名確認プロキシにも同じ値を設定します |
| `API_ENABLED` | 通常は設定しません（将来の Web 予約画面を接続するときだけ `true`） |

## 4. シートを自動作成する

エディタ上部の関数選択で **setupSpreadsheet** を選び「実行」します（初回は権限の承認が必要です）。
次のシートが作られます: `CONFIG`、`CUSTOMERS`、`SERVICES`、`RESERVATIONS`、`INQUIRIES`。
何度実行しても、既存のデータは消えません（足りないシート・列・設定だけを追加します）。

## 5. 店舗情報を入力する

- `CONFIG` シートの `value` 列を確認・入力します。
  - 営業時間は `hours.mon` 〜 `hours.sun` に `10:00-19:00` の形式で、定休日は `closed` と入力します。
  - `reservation.capacity` は同じ時間に受けられる人数（席数・スタッフ数）です。
- 必要に応じて、各ワークフローで使用する情報を該当するシートに入力します。`active` を設定できる項目は、TRUE にした行のみが使用されます。

## 6. Web アプリとして公開する（作業者向け）

1. エディタ右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行: 自分／アクセスできるユーザー: 全員
2. 表示された URL（`…/exec`）を控えます。**この URL は LINE には直接設定しません。** 次の手順の署名確認プロキシに設定します。

## 7. 署名確認プロキシを置き、LINE とつなぐ（作業者向け）

LINE から届く通信が本物かどうかを確かめる小さなプログラム（署名確認プロキシ）を Cloudflare に置き、
その URL を LINE の Webhook URL に設定します。手順は [LINE_SETUP.md](LINE_SETUP.md) の「2」「3」です。

## 8. リッチメニューを登録する（作業者向け）

納品物の画像と設定を、ファクトリーのコマンドで LINE に登録します。まずテスト用アカウントで確認し、問題がなければ本番に登録します。
手順は [LINE_SETUP.md](LINE_SETUP.md) の「4」です。

## 9. 動作確認

スマートフォンの LINE アプリで [E2E_TEST.md](E2E_TEST.md) のチェックリストを上から順に確認します。

## 10. 毎日の運用

- 予約リクエストが届いたら内容を確認し、`RESERVATIONS` の `status` を `CONFIRMED`（確定）または `CANCELLED` に変更してください。お客様への確定連絡は LINE チャットで行います。
- お問い合わせは `INQUIRIES` の `status` を `IN_PROGRESS` → `DONE` と更新すると管理しやすくなります。
- シートの **見出し行（1行目）は変更・削除しないでください**。システムが列を見つけられなくなります。

## うまく動かないとき・元に戻したいとき

[ROLLBACK.md](ROLLBACK.md) を参照してください。リッチメニュー、LINE との接続、プログラム、設定のそれぞれを元に戻す方法があります。

## セキュリティについて

- スプレッドシートにはお客様の個人情報（LINE ID・お名前・連絡先）が入ります。共有は必要な方だけにしてください。
- チャネルアクセストークン、チャネルシークレット、`WEBHOOK_KEY` はパスワードと同じです。漏れた場合は LINE Developers でトークンを再発行し、チャネルシークレットと `WEBHOOK_KEY` も新しい値に変更してください（[ROLLBACK.md](ROLLBACK.md)「4」）。
