# Apps Script（GAS）の設定 — Demo Nail Salon（デモ）

作業者向けの資料です。オーナー様が操作するのは「5. 更新したとき」の確認だけです。

## 1. プログラムを入れる

```bash
cd gas
npm install
npm run typecheck
npm test            # LINE の受付テストを含む全テストが通ることを確認
npm run build       # build/Code.js を作成
cp .clasp.json.example .clasp.json   # scriptId を記入（.clasp.json は Git に入れない）
npx clasp push
```

## 2. スクリプト プロパティ

[SETUP.md](SETUP.md)「3」の表のとおりに登録します。値はここ以外（ファイル、チャット、スプレッドシート）には書きません。

## 3. ウェブアプリとして公開

「デプロイ」→「新しいデプロイ」→「ウェブアプリ」。実行ユーザー: 自分、アクセス: 全員。
表示される `…/exec` の URL は、署名確認プロキシの `GAS_WEBAPP_URL` に設定します（[LINE_SETUP.md](LINE_SETUP.md)「2」）。

- LINE からの通信は、署名確認プロキシを通ったものだけが受け付けられます（URL に `WEBHOOK_KEY` が付いているもののみ）。
- `WEBHOOK_KEY` が未設定、または 16 文字未満のときは、すべての LINE の通信を拒否します。

## 4. 初回の実行

1. **setupSpreadsheet** を実行してシートを作ります。
2. 実行ログ（「実行数」）にエラーがないことを確認します。

## 5. 更新したとき

プログラムを更新したら「デプロイを管理」→ 既存のデプロイを「編集」→ バージョン「新しいバージョン」で更新します。
**新しいデプロイを作ると URL が変わる**ため、署名確認プロキシの設定も変更が必要になります。

## 補足: setupRichMenu
