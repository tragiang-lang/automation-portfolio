# Core Assets

Versioned, client-free building blocks. **Do not edit a released file in place.** Bump its
version (compatible change) or create a `-v<N+1>` asset (breaking change), then run
`npm run factory -- validate` and `npm run factory -- lock-assets`.

| Folder | Kind | Id convention |
|---|---|---|
| `industries/<category>/` | `industry` | `hair-salon-v1` (`industry: "hair_salon"`) |
| `industries/common/` | `intent-catalog` | `customer-intents-v1` |
| `workflows/<area>/` | `workflow` | `inquiry-basic-v1` |
| `actions/<id>/v<major>.json` | `action` | `createInquiry` → referenced as `createInquiry@1` |
| `spreadsheet-schemas/` | `spreadsheet-schema` | `inquiries-basic-v1` (sheet names unique across schemas) |
| `rich-menu/layouts/` | `rich-menu-layout` | `grid-2x3-v1` |
| `rich-menu/menus/` | `rich-menu` | `salon-basic-v1` |
| `design-presets/` | `design-preset` | `quiet-luxury-v1` |
| `qa-rules/` | `qa-rules` | `qa-rules-v1` |
| `gas-modules/` | TS source + `modules.json` | module ids `runtime`, `inquiry`, … |
| `asset-lock.json` | release lock | generated by `lock-assets` |
